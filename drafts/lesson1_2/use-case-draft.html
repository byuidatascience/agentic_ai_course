Fix it

The function works fine. The description doesn’t. Rewrite the docstring so the agent knows exactly when and how to use it:

@tool
def check_inventory(item: str, color: str = None) -> str:
    """Check how many units of an item are in stock, optionally filtered by color.
    Use this whenever a customer asks whether an item is available or in stock."""
    fake_stock = {
        ("hoodie", "blue"): 4,
        ("hoodie", "black"): 12,
        ("t-shirt", "blue"): 30,
    }
    count = fake_stock.get((item.lower(), color.lower() if color else None), 0)
    label = f"{color} {item}" if color else item
    return f"We have {count} {label}(s) in stock." if count else f"We're out of {label} right now."

agent = create_agent(
    model="google_genai:gemini-2.5-flash",
    tools=[check_inventory],
    system_prompt="You are a helpful retail assistant.",
)

response = agent.invoke({"messages": [{"role": "user", "content": "Do you have the blue hoodie in stock?"}]})
print(response["messages"][-1].content)

Expected output: We have 4 blue hoodie(s) in stock. Now it works — because the docstring told the agent what the tool does and when to reach for it.

Problem 2 — Shelley asks a follow-up

Shelley isn’t done: “What about in black?” Try it as a new question, same as before:

response = agent.invoke({"messages": [{"role": "user", "content": "What about in black?"}]})
print(response["messages"][-1].content)

The agent has no idea what “it” refers to — it never saw the word “hoodie” in this call. It might ask what item you mean, or guess wrong.

NoteDiscuss

The tool worked fine a minute ago — so why does the agent suddenly seem to have forgotten everything?

What’s missing

The model doesn’t remember anything between calls. Each agent.invoke() starts from nothing unless you hand it the conversation so far. Fill in the blank below to carry the first exchange forward into the second:

first_response = agent.invoke({"messages": [{"role": "user", "content": "Do you have the blue hoodie in stock?"}]})

messages = ____  # FILL IN — how do we carry the conversation so far into the next call?
messages.append({"role": "user", "content": "What about in black?"})

second_response = agent.invoke({"messages": messages})
print(second_response["messages"][-1].content)

Filled in: messages = first_response["messages"]. Run it now.

Expected output: We have 12 black hoodie(s) in stock. This time it resolves “it” correctly, because the whole conversation — not just the latest question — went into the call.
