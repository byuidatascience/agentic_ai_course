Six modes

Each mode is named for the lever that fixes it

1 · Tool The connection to the outside world breaks. tool descriptions, schemas

2 · Grounding Says things nothing it retrieved supports. retrieval, what it may answer

3 · State What it needs is lost, stale, or poisoned. memory design

4 · Control Doesn’t stop, doesn’t finish, or wanders. control flow, step limits

5 · Specification Did what was said, not what was meant. instructions, success criteria

6 · Safety Harmful or unapproved, even if it “worked.” guardrails, permissions, HITL

  • Reveal one at a time; write each on the whiteboard as it appears.
  • Each one is a lever they already built in Unit 1, read backwards. Naming it is naming the fix.
  • Reference sheet: projects/project2_resources/failure_modes.qmd

Three ways to describe any failure

silent ↔︎ loud Would anyone notice without the trace?

isolated ↔︎ cascading Where is the earliest bad span?

model ↔︎ code A bad guess, or a bug?

  • Silent failures are the dangerous ones. Most of today’s are silent.
  • Cascading: look for the first bad span, not the last.
  • Students blame the model by reflex. Ask “would this happen every time?”
