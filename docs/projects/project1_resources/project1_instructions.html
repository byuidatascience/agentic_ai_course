Project 1: Personal Assistant Agent

Build a big beautiful personal assistant agent that you would actually use daily.

You start this in Week 2 and add to it as you learn new skills. It is due TBD (mid to late week 4 most likely).

The Point

Build something you want. Wire it up to real tools and give it real power.

Rules

  • No coding agents allowed (unless you build the coding agent using LangChain)
  • Consult peers before AI
    • Your classmates and their repo’s are a great source of inspiration; but only copy code if you understand it.
  • Consult YOUR agent for help before chat interfaces (like ChatGPT)
    • Turning to your agent first gives a natural friction point that drives motivation for improvements.
  • No burnout allowed
    • This is an open-ended trial-by-fire project that requires a lot of thought.
    • Pause if you are strained or exhausted.
    • Bringing it to class unfinished is fine. You can get help from your peers.
    • Consider setting a time limit on any problem you get stuck on.

What You Build

1. Your own repository

Create a GitHub repository for your agent. This is yours and it is public, so it can go in your portfolio later.

Your agent’s memory directory must be in .gitignore. It will hold real information about you and that does not belong on GitHub. Commit an example_memory/ folder with fake data instead so the repo still runs for anyone who clones it.

2. A main agent

One agent receives your prompt and decides what tools to use and what to delegate to subagents.

3. Personal memory

Allow your agent to store and retrieve information about you: your classes, your goals, your resume, your preferences, whatever you want it to know.

4. At least 1 subagent of your choosing

Pick from this menu, or create your own idea (within reason):

  • Job hunt. Tailors your resume to a job description you paste in, tracks applications, drills interview questions, “2-hour job search” framework (consider looking that up)
  • Money. Reads a CSV export from your bank, categorizes spending, answers questions about it. Or plans meals and groceries on a budget.
  • Coursework. You paste in your syllabi. It answers questions about deadlines and requirements.
  • Scripture and study. Search conference talks, brainstorm ministering ideas, track study goals.
  • Roommates. Chore rotations, splitting bills, apartment logistics.
  • Your own code. Points it at one of your repos (maybe even its own). Explains it, finds your TODOs, drafts commit messages.
  • Translator. Takes a concept you don’t understand and relates it to things it knows you understand in language you are familiar with.
  • Learning. Personal tutor, spaced repetition practice, quizzes you

5. Required capabilities

Across the whole agent, you must use:

  • Read and write to the file system
  • Persistent personal memory (file/db/store)
  • Conversation history
  • Connect to LangChain MCP

Deliverables

  1. A working agent. It runs and does something.
  2. A README.md in your repo. What your agent does, how to run it, what subagents it has, and what it cannot do.
  3. A self-reflection in Canvas. What your agent does well, what it does poorly, and where you expected it to work and it did not. Be specific. Include examples.
